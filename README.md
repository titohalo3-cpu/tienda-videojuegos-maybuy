# MayBuy · Tienda de videojuegos

Proyecto de 2.º de DAW (Desarrollo Web en Entorno Cliente). Web de una tienda de videojuegos nuevos y de segunda mano hecha con HTML, CSS y JavaScript sin frameworks.

- **Login por roles**: cliente, trabajador y administrador.
- **Menú lateral** como componente (`<menu-principal>`) con Más vendidos, Ofertas y Más populares.
- **Lista de juegos** como componente (`<lista-juegos>`): filtrar, ordenar y dar de alta, consultar, modificar y eliminar juegos.
- Datos en JSON y cambios guardados en `sessionStorage`.

Para probarla hay que abrirla desde un servidor local (por ejemplo, Live Server) y entrar por `html/login.html`.
